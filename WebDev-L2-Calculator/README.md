# Calculator

This is a simple calculator built using HTML, CSS, and JavaScript. I created this project to strengthen my JavaScript fundamentals by working with DOM manipulation, event handling, and application logic.

Instead of focusing only on the UI, I spent most of the time understanding how a calculator actually works behind the scenes—how numbers, operators, and results are managed using JavaScript.

---

## Features

- Perform basic arithmetic operations
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Decimal number support
- Backspace functionality
- Clear (C) button
- Prevents multiple decimal points
- Handles divide by zero
- Prevents invalid calculations
- Supports operator replacement before entering the second number
