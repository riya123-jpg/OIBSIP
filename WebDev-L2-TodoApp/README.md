# OIBSIP Level 2 - Todo App

## Objective

The objective of this task was to build a simple and interactive Todo application
using HTML, CSS, and JavaScript.

The application allows users to manage their tasks through a clean and
user-friendly interface.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Interactive task management
- Responsive and simple user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
